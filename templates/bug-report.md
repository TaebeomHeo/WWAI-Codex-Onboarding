# Bug Report Skeleton / 버그 리포트 템플릿

Fill bilingual where useful; keep concise. / 필요 시 한/영 병기, 간결하게.

- Title / 제목: [Feature] brief issue  
- Environment / 환경: app version, browser/OS, account role  
- Preconditions / 선행 조건: data/setup/logins  
- Steps to Reproduce / 재현 절차: 1) … 2) …  
- Expected / 기대 결과: …  
- Actual / 실제 결과: …  
- Evidence / 증빙: screenshot/log/ID  
- Severity / 심각도: Blocker/Critical/Major/Minor  
- Notes / 비고: workaround? repro rate?  
- Translation / 번역: If reporting cross-team, add short EN summary. / 타팀 전달 시 짧은 영문 요약 추가

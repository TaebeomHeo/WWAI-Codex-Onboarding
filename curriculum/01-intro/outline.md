# 01. Onboarding / 오리엔테이션

## Session Goals / 세션 목표
- Understand what Codex is and where it fits in work. / Codex 정체와 활용 범위 이해
- Learn safety basics: data handling, PII, escalation. / 안전 가이드(개인정보, 보안, 에스컬레이션)
- Experience first prompt: clear role, task, format. / 첫 프롬프트 실습(역할/작업/형식)

## Agenda / 아젠다
1) Why Codex for non-devs? / 비개발자가 Codex를 써야 하는 이유  
2) Chat형 vs 에이전트형(Codex) 차이와 장점 / 챗 vs 실행  
3) Safe use + boundaries / 안전 수칙과 한계  
4) Prompt basics with mini demo / 기본 프롬프트 + 데모  
5) Hands-on: rewrite a vague ask / 실습: 모호한 요청을 명확하게 바꾸기  
6) Homework: bring 1 real task / 과제: 실제 업무 1건 가져오기  

## Materials / 자료
- Slides: KR/VN-EN side-by-side. / 슬라이드: 한/영 병기
- Cheat-sheet: prompt pattern + red flags checklist. / 치트시트: 프롬프트 패턴, 위험 신호 체크리스트
- Example prompts: onboarding email, meeting recap. / 예시: 온보딩 이메일, 미팅 요약
- Playbook: chat vs agent difference (`playbooks/chat-vs-agent.md`). / 챗 vs 에이전트 비교 자료

## Safety Reminders / 안전 수칙
- No secrets/PII; sanitize inputs. / 비밀/개인정보 금지, 입력 정제
- If unsure, ask Codex to restate assumptions. / 불확실 시 가정사항 재진술 요청
- Keep a human in the loop; sample-check outputs. / 반드시 사람 검토 단계 유지

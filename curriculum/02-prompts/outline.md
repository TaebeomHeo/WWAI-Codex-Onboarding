# 02. Prompt Fundamentals / 프롬프트 기본기

## Goals / 목표
- Build robust prompts: role, task, constraints, examples, format, verification. / 견고한 프롬프트 구성요소 익히기
- Practice rewriting unclear asks into stepwise instructions. / 모호한 요청을 단계 지시로 변환
- Learn quick self-checks to reduce hallucination. / 환각 줄이는 셀프체크 익히기

## Agenda / 아젠다
1) Prompt pattern teardown (role/task/limits/output). / 프롬프트 패턴 분해  
2) Few-shot vs zero-shot: when to use. / 퓨샷 vs 제로샷 사용 시점  
3) Format control: tables, bullet spec, JSON caution. / 형식 제어, JSON 사용 시 주의  
4) Verification add-ons: “reflect & fix”, assumptions list. / 검증 추가(반성/가정 리스트)  
5) Hands-on: rewrite 3 workplace asks. / 실습: 업무 요청 3건 재작성  

## Exercises / 실습
- Take vague ask: “검수 리스트 만들어줘” → add context, constraints, output table. / 모호 요청을 구체화
- Email tone shift: friendly vs formal; English/Korean switch. / 이메일 톤 변경, 한/영 전환
- Generate questions to clarify missing info. / 정보 공백을 메울 질문 생성

## Takeaways / 정리
- Use the pattern: Role + Task + Constraints + Format + Examples + Verify. / 패턴 암기
- Always state domain vocab or definitions. / 용어 정의를 명시
- Add small test cases to anchor outputs. / 앵커용 미니 테스트 케이스 삽입

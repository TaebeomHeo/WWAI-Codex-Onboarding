# 04. Office Automation / 일반 업무 자동화

## Goals / 목표
- Automate routine communications and reporting. / 커뮤니케이션·보고 자동화
- Clean/transform spreadsheet and text data with Codex guidance. / 스프레드시트·텍스트 정리
- Build SOPs and checklists that teams can reuse. / 재사용 가능한 SOP·체크리스트 작성

## Agenda / 아젠다
1) Email/report drafting: tone, length, bilingual. / 이메일·보고서 작성(톤/길이/한영)  
2) Meeting/record summarization → action items. / 회의 요약 → 액션 아이템  
3) Spreadsheet helpers: formulas, data cleanup plans. / 스프레드시트 보조(수식, 정제 계획)  
4) SOP generation with guardrails. / 가드레일이 있는 SOP 생성  
5) Mini-capstone prep: pick a real task. / 미니 캡스톤 준비

## Exercises / 실습
- Draft bilingual status email from bullet notes. / 불릿 노트로 한/영 상태 이메일 작성
- Convert messy CSV spec to clean schema + sample rows. / 지저분한 CSV를 스키마/샘플로 정제
- Extract action items from meeting transcript; verify with checklist. / 회의록에서 액션 추출 후 검증
- Create SOP: “Inbound ticket triage” with levels. / 티켓 분류 SOP 작성

## Tips / 팁
- Ask Codex to propose format first, then fill. / 형식을 먼저 제안받고 채우기
- Include tone, audience, and do/don’t bullets. / 톤/대상/한다-안한다 항목 명시
- Add a verification step: length check, jargon check, red/amber/green summary. / 길이·전문용어·RAG 요약 검증

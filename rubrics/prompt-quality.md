# Prompt Quality Rubric / 프롬프트 평가 루브릭

Score 1–5 for each; aim for ≥4. / 각 항목 1~5점, 4점 이상 목표.

- Clarity / 명확성: Task, scope, success criteria are explicit. / 작업·범위·성공 기준이 분명
- Context / 컨텍스트: Audience, system, data ranges provided. / 대상·시스템·데이터 범위 포함
- Constraints / 제한: Length/tone/tools/do-don’t listed. / 길이·톤·사용/금지 사항 명시
- Format control / 형식 제어: Table/sections defined; avoid vague “write it well.” / 표·섹션 지정, 모호 지시 없음
- Examples / 예시: Anchors or test cases present when needed. / 필요 시 예시/테스트 케이스 제공
- Verification / 검증: Self-check request included. / 셀프 체크 요청 포함
- Language fit / 언어 만족: KR/EN choice and tone match audience. / 언어/톤이 대상에 적합

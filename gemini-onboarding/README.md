# Gemini CLI 온보딩

이 프로젝트는 Gemini CLI를 에이전트처럼 사용하는 방법을 배우기 위한 교육 자료를 제공합니다.

## 소개

Gemini CLI는 강력한 AI 에이전트로, 파일 시스템 조작, 코드 생성, 웹 검색 등 다양한 작업을 수행할 수 있습니다. 이 교육 자료는 Gemini CLI의 기본 사용법부터 시작하여, 복잡한 작업을 자동화하는 방법까지 단계별로 안내합니다.

## 시작하기

이 교육 자료를 시작하기 전에, Gemini CLI가 이미 설치되어 있고, 현재 프로젝트 디렉토리에서 Gemini CLI를 사용할 수 있는 상태여야 합니다.

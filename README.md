# WWAI-Codex-Onboarding

한국/베트남(영어) 비개발자 대상 Codex 업무 자동화 교육 자료 리포지토리입니다. Curriculum, exercises, templates가 모두 한글과 영어로 병기되어 있습니다.

- Audience: KR 비개발자, VN/EN 비개발자
- Focus: SW 테스트 자동화 + 일반 오피스 업무 자동화
- Structure: 세션 노트, 실습 과제, 템플릿, 루브릭, 샘플, 플레이북
- Setup: VS Code + Codex extension + Python/Node 설치 가이드는 `playbooks/env-setup.md` 참고

This repo hosts bilingual (KR + EN) learning assets to teach non-developers how to use Codex for broad workflow automation, with testing as a primary but not exclusive use case.

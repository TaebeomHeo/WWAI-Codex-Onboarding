# 부록: Antigravity App 100% 활용하기

이 문서는 에이전트와의 협업을 넘어, Antigravity **앱 자체의 기능**을 활용하여 팀 생산성을 높이는 팁을 다룹니다.

## 1. 대화 내용 공유하기 (Sharing Context)

동료에게 내가 에이전트와 어떤 대화를 나눴는지 공유해야 할 때가 있습니다.

### 상황 A: "이 에러 어떻게 해결했어?"

내가 에이전트와 함께 디버깅한 과정을 동료에게 보여주고 싶을 때:

- **Copy & Paste**: 대화창의 텍스트를 드래그하여 메신저(Slack, Teams)에 붙여넣습니다. 코드 스니펫(Code Snippet)은 서식이 유지되므로 가독성이 좋습니다.
- **Screenshot**: 복잡한 맥락이 포함된 경우, 화면 전체를 캡처하여 공유합니다.

### 상황 B: "이거 에이전트가 정리해준 거야"

에이전트가 작성한 요약 보고서나 초안을 공유할 때:

- 에이전트에게 **"Markdown 파일로 저장해줘"**라고 시키세요.
- 생성된 `.md` 파일을 팀 채팅방이나 위키(Notion, Confluence)에 업로드하면 깔끔합니다.

## 2. 나만의 스킬 공유하기 (Skill Sharing)

내가 만든 "기가 막힌 프롬프트"는 팀의 자산입니다. 혼자만 쓰지 말고 동료들에게 공유하세요.

### Instruction File = Skill

실습 3에서 배운 **Instruction File (`.md`)**은 일종의 **"스킬(Skill)"**입니다.

- "주간보고 작성 스킬" (`weekly-report.md`)
- "버그 리포트 분석 스킬" (`bug-analysis.md`)

### 공유 방법: Git 활용

이 파일들을 팀의 공용 저장소(Repository)에 올려두세요. (예: `templates/` 폴더)

1. 내가 만든 `.md` 파일을 커밋 & 푸시합니다.
2. 동료에게 말합니다.
   > "아까 올린 `templates/bug-analysis.md` 파일 써봐. 에러 로그만 긁어주면 원인 분석 기가 막히게 해줘."
3. 동료는 해당 파일을 다운받아 자신의 Antigravity에 드래그하거나 경로를 입력하여 바로 사용할 수 있습니다.

## 3. 히스토리 관리 (Chat History)

작업이 많아지면 왼쪽 사이드바의 채팅 목록이 복잡해집니다.

### 세션 이름 변경 (Renaming)

에이전트는 첫 대화를 보고 자동으로 제목을 정하지만, 나중에 찾기 쉽게 수정하는 것이 좋습니다.

- **Tip**: `[Jira]` `[Refactor]` `[Study]` 같은 **태그(Tag)**를 제목 앞에 붙이면 시인성이 좋아집니다.

### 주제별 세션 분리

하나의 채팅창에서 너무 많은 주제(버그 수정하다가 점심 메뉴 추천받다가 뉴스 요약하기)를 다루지 마세요.

- **Context Pollution**: 이전 대화 맥락이 섞여서 에이전트가 헷갈려할 수 있습니다.
- 새로운 주제는 과감하게 **"New Chat"**을 눌러서 새 깨끗한 도화지에서 시작하세요.
